QRCode Generator

A lightweight, customizable QR Code Generator built using pure HTML, CSS, and JavaScript.
You can easily generate, preview, and download QR codes as SVG or PNG files.

This project is a further development based on qrcode-svg by on 

Features

Adjustable QR settings (dimension, padding, pattern, error correction, colors)

Custom face and background colors with transparency support

SVG optimization toggle

Download QR code as SVG or PNG

Fully responsive layout

No external dependencies other than qrcode.min.js

How to Use

Clone or download this repository.

Open the index.html file in your browser.

Type your message or link into the text box.

File Structure

```
project/
│
├── index.html        # Main HTML file
├── qrcode.min.js     # QRCode library
├── favicon.png       # Optional icon
└── README.md         # Documentation
```

Customization

You can modify the default text messages inside the script section of index.html.

You can style the UI by editing the CSS directly in the <style> section.
